Mettre en ligne gratuitement

Stack 100% gratuite : Supabase (base de données) + Vercel (hébergement) + Resend (emails).

1
Supabase — créer le projet
Compte gratuit sur supabase.com. Récupère dans Settings → API : l'URL du projet et la clé anon public.
2
Supabase — créer les tables
Dans SQL Editor, exécute :
CREATE TABLE kinklist (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  username text NOT NULL UNIQUE,
  email text,
  answers jsonb DEFAULT '{}',
  compare_token text UNIQUE,
  updated_at timestamptz DEFAULT now()
);

CREATE TABLE kink_history (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  username text NOT NULL,
  item text, side text,
  from_val text, to_val text,
  created_at timestamptz DEFAULT now()
);

CREATE TABLE invitations (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  created_by text NOT NULL,
  label text,
  token text UNIQUE NOT NULL,
  used_by text,
  used_at timestamptz,
  created_at timestamptz DEFAULT now()
);

-- RLS policies
ALTER TABLE kinklist ENABLE ROW LEVEL SECURITY;
ALTER TABLE kink_history ENABLE ROW LEVEL SECURITY;
ALTER TABLE invitations ENABLE ROW LEVEL SECURITY;
CREATE POLICY "all" ON kinklist USING (true) WITH CHECK (true);
CREATE POLICY "all" ON kink_history USING (true) WITH CHECK (true);
CREATE POLICY "all" ON invitations USING (true) WITH CHECK (true);
3
Resend — emails gratuits
Compte sur resend.com → API Keys → crée une clé. Gratuit jusqu'à 3 000 emails/mois. Garde la clé pour l'étape suivante.
4
Vercel — déployer
1. Crée un repo GitHub avec ces 2 fichiers : index.html et api/send-email.js
2. Sur vercel.com → importe le repo
3. Dans Settings → Environment Variables, ajoute :
RESEND_API_KEY = ta clé Resend
ADMIN_EMAIL = ton email (pour les alertes admin)
5
Configurer l'app
Clique sur ⚙ Config sur la page d'accueil et entre ton URL Supabase + clé anon. Tout est sauvegardé dans ton navigateur.
💡 Sans config : l'app fonctionne en mode local (navigateur uniquement). Avec Supabase + Resend configurés, tout est synchronisé et tu reçois des emails.
